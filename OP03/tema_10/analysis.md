# Исследование Instagram-кампании
Выборка: Session source = instagram И Session campaign = backend_guide. Для сравнения с Direct создать отдельную вкладку без общего ограничения instagram. Период и часовой пояс одинаковы в Reports и Explore.

| Вопрос | Измерение | Показатель |
|---|---|---|
| Сколько переходов из кампании? | Источник/канал сеанса, кампания сеанса | Сеансы |
| С чего начался визит? | Стартовая страница | Сеансы |
| Как часто нажимают CTA, начинают и отправляют форму? | Название события | Event count по каждому событию |
| В какой доле сеансов была отправка? | Кампания сеанса | Session key event rate для generate_lead |

Free form: строки — кампания и стартовая страница, столбцы — категория устройства, значения — сеансы и ключевые события. Сегменты сеансов Instagram и Direct. Отметка generate_lead как ключевого события и дата её включения требуют сверки.

Funnel: закрытая воронка, непрямые переходы, без ограничения времени. Шаги session_start → cta_click → form_start → generate_lead. Для соседних шагов A, B абсолютная потеря A−B, доля потерь (A−B)/A. При A=0 доля не определена. Вычислить максимумы отдельно; сравнить mobile и desktop в тех же условиях. Пользователь может продолжить в другом сеансе.

Path: начальная точка cta_click, узлы Event name, метрика Event count. Обратное исследование заканчивается generate_lead. Общий фильтр Event name удалил бы промежуточные узлы. Attribution: выбрать generate_lead и сравнить вклад каналов за один период. Custom Insight: снижение сеансов кампании относительно предыдущей недели. Отчёт для коллекции: Session campaign, Session source / medium, Sessions и Session key event rate.

Сверка: уникальные непустые request_id в таблице за тот же период и в том же часовом поясе. В учебной выгрузке v2 нет instagram / backend_guide; это другой набор данных. Выгрузка личного GA4 не предоставлена. Число сеансов, фактические переходы, самый большой отток и результат атрибуции неизвестны.

Гипотеза: конкретное обещание результата на кнопке гайда увеличит долю читателей, которые начнут заполнять форму. Проверка: изменить только текст кнопки и сравнить form_start среди открывших гайд в параллельных группах, отдельно на mobile и desktop.
