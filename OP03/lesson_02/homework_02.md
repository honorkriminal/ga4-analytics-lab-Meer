# 2. Где теряются заявки на учебный курс

Меер Джонатан · ОП.03 · 24.11.2026 · группа не указана

Объект — учебный сайт GA4 Analytics Lab. На нём можно проследить один и тот же путь от материала до заявки на backend. Целевое действие — сохранение уникальной заявки.

| Этап | Условие перехода | Метрика |
|---|---|---|
| Переход из публикации | Открылась страница материала | Сеансы кампании |
| Чтение | Посетитель выбрал переход к форме | Пользователи с cta_click |
| Заполнение | Начался ввод | Пользователи с form_start |
| Отправка | Валидная форма отправлена | События generate_lead |
| Приём | В таблице появился новый ID | Уникальные request_id |

**Кейс 1.** В школе Елены Сягло выбирали, какая версия лендинга лучше доведёт посетителя до следующего шага. Маркетологи поочерёдно запускали пять версий, изучали время на странице в Вебвизоре и дорабатывали содержание. Для широкого запуска выбрали версию с наибольшей конверсией. Точный прирост за счёт лендинга не опубликован. Для учебного сайта можно сравнить две формулировки кнопки при одинаковом источнике трафика.

**Кейс 2.** Фоксфорду требовалось познакомить школьников с продуктом через новую площадку. Путь шёл от баннера на Ozon к регистрации и получению результата теста. Агентство сравнивало категории размещений и стоимость лида. Результат теста получили 11,6% посетителей. Контрольная группа и прирост относительно прежнего размещения не приведены. Для учебного сайта переносим разметку каждого размещения и измерение получения материала.

| Возможная потеря | Изменение | Как проверить |
|---|---|---|
| Посадочная страница не объясняет, что получит читатель (GetCourse) | Указать содержание гайда в первом экране | Случайно разделить посетителей; сравнить пользователей с CTA среди открывших страницу |
| Слишком много обязательных полей (Baymard, PR Mediacom) | Оставить контакт и направление, сделать имя необязательным | Сравнить уникальные заявки на начавшего форму, проверить пригодность контактов |
| Человек бросает форму на поле с неясным форматом (Яндекс) | Дать пример ввода и ошибку у поля | Сравнить form_error по полям и повторную успешную отправку |

### GA4
Проект настроек: аккаунт учебных работ → ресурс «GA4 Analytics Lab — Meer» → веб-поток учебного сайта. Часовой пояс Москва, валюта RUB, цель — получение потенциальных клиентов. Числовой Stream ID описывает поток; Measurement ID вида G-… устанавливается на страницы. Создание ресурса, значения ID и состояние Enhanced Measurement в личном кабинете не подтверждены.
